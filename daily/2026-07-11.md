## Beginner Review: Prefill-Decode Disaggregation

PD disaggregation separates prefill and decode onto different workers or clusters.

Normal serving:

```text
same engine does prefill and decode together
```

PD disaggregation:

```text
prefill workers:
process prompts and produce KV cache

decode workers:
consume KV cache and generate output tokens
```

## Why Separate Them

Prefill and decode have different resource shapes.

Prefill:

- processes the full prompt,
- is compute-intensive,
- builds the initial KV cache,
- mainly affects TTFT.

Decode:

- generates one token at a time,
- repeatedly reads/writes KV cache,
- is memory/KV-cache intensive,
- mainly affects TPOT/ITL.

If they are colocated, they can interfere:

```text
large prefill batch -> decode waits -> ITL gets worse
many decode requests -> prefill waits -> TTFT gets worse
```

## KV Cache Transfer

The hard part is transferring KV cache from prefill workers to decode workers:

```text
prompt
-> prefill worker computes KV cache
-> KV cache transfer
-> decode worker generates tokens
```

If KV transfer is slow, PD disaggregation may lose its benefit.

## Mooncake Connection

Mooncake is a KVCache-centric disaggregated architecture.

Beginner version:

```text
Mooncake separates prefill and decode clusters
and treats KV cache placement/transfer/reuse as central
```

It uses underutilized CPU, DRAM, SSD, and NIC resources to build a disaggregated KV cache pool.

## Chinese Interview Sentence

```text
Prefill-decode disaggregation 是把 LLM 推理的 prefill 和 decode 两个阶段拆到不同 worker 或集群上。原因是这两个阶段资源特性不同：prefill 处理整个 prompt，偏计算密集，主要影响 TTFT；decode 每次生成一个 token，不断读写 KV cache，偏内存和 KV cache 密集，主要影响 TPOT/ITL。放在同一个 engine 里时，大 prefill batch 可能阻塞 decode，导致 inter-token latency 变差；大量 decode 也可能让新的 prefill 排队，导致 TTFT 变差。

PD 分离后，prefill worker 负责处理 prompt 并生成 KV cache，decode worker 接收 KV cache 后继续生成 token。这样可以分别给 prefill 和 decode 配不同并行策略、不同资源规模和不同调度策略。但难点是 KV cache transfer：prefill 生成的 KV cache 必须高效传到 decode worker，如果网络或传输层太慢，收益会被抵消。

Mooncake 这类 KVCache-centric 架构进一步把 KV cache 当成一等资源，关注 KV 的放置、传输、复用和分布式缓存池。面试里我会说，PD disaggregation 的核心 tradeoff 是减少 prefill/decode phase interference，同时控制 KV transfer 和调度复杂度；评估时要看 TTFT、TPOT/ITL、p99、KV transfer time、GPU utilization 和 goodput under SLO。
```
